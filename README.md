A two-line robot apology: it charged the toothbrush all night and left the phone at 2%, and learned to label each charger by the thing it feeds.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`): line one
owns the mistake, line two names the lesson and the changed behaviour.
